# SR-campus-Direct

A campus-focused platform designed to streamline direct connections and services.

## Features
* **Direct Communication:** Connect quickly within the campus ecosystem.
* **Streamlined Services:** Access relevant tools and updates easily.

## Tech Stack
* **Frontend:** React / Vite
* **Backend:** Node.js / Go
* **Database & Auth:** Supabase

## Getting Started

### Prerequisites
Make sure you have Node.js and npm installed on your machine.
